# License decision — resolved for the draft

The public evidence release uses a split licensing model:

- **CC BY 4.0** for documentation, evidence tables, CSV datasets, release-specific figures, and research/evidence material;
- **Apache-2.0** for source code and executable test harnesses, if/when these are added to the public repository;
- third-party material retains its original license.

For this draft, the main release is evidence/documentation rather than a software package, so `CITATION.cff` declares `CC-BY-4.0`.
